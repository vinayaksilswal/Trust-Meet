# Changelog

## 0.1.0 development

- Introduced the Next.js workspace, FastAPI API, PostgreSQL migrations, Redis rate limiting and Compose configuration.
- Added email registration, verification and recovery, session revocation and development adult eligibility.
- Added one-to-one text, audio and video via LiveKit, with both invitation-based and queue-based discovery.
- Added report collection, user blocking, session expiry and room cleanup.
- Added scheduled private rooms with expiring invites, optional passwords, capacity, host approval, and LiveKit moderation controls.
